# Техническая спецификация (Overview): Веб-сервис выбора технологии строительства

## 1. Суть проекта
Мини-приложение (веб-сервис) для многокритериального подбора оптимальной технологии строительства малоэтажного жилого дома. 
Пользователь вручную проходит опрос, выставляя оценки важности 6 критериев (через ползунки от 1 до 5). Сервис адаптирует базовые экспертные веса под профиль пользователя и с помощью математической модели **TOPSIS** ранжирует 4 доступные технологии, выдавая наилучший вариант.

Метод **AHP** (метод анализа иерархий) уже применен заранее — сервис использует готовые рассчитанные константы (базовые веса). Пересчитывается только адаптация весов пользователя и сам TOPSIS.


## 2. Архитектура пользовательского интерфейса (UI/UX)

Интерфейс состоит из 2-х основных логических блоков.

### Блок 1: Опросник (Ввод данных)
6 ползунков со значениями от 1 до 5 (по умолчанию 3). Пользователь обязан пройти опрос, чтобы получить индивидуальный результат.
*   **1** — Несущественно
*   **2** — Второстепенно
*   **3** — Нейтрально
*   **4** — Значимо
*   **5** — Принципиально важно

**Список вопросов (Пользовательские критерии `U`):**
*   **К1 — Стоимость строительства:** «Насколько для вас важно снизить затраты на возведение дома?»
*   **К2 — Годовые эксплуатационные затраты:** «Насколько важна экономичность дома в ежегодном содержании?»
*   **К3 — Продолжительность строительства:** «Насколько важно построить дом быстро?»
*   **К4 — Расчётный срок службы:** «Насколько важна долговечность дома?»
*   **К5 — Звукоизоляция:** «Насколько важна тишина и защита от шума в доме?»
*   **К8 — Ремонтопригодность:** «Насколько важна простота ремонта и обслуживания дома?»

*(Скрытые инженерные критерии К6, К7, К9, К10, К11 в UI не выводятся, их вес остается неизменным).*

### Блок 2: Результат
Динамически обновляемый блок (пересчет при каждом движении ползунка или после нажатия кнопки "Рассчитать" — на усмотрение реализации):
*   **Карточка Победителя:** Название лучшей технологии и заранее заготовленный текст-описание (см. раздел 5).
*   **Рейтинг (Leaderboard):** Список всех 4 технологий с их коэффициентом близости `C` (от 0 до 1), отсортированный по убыванию.

## 4. Математическое ядро (Алгоритм расчета)

При получении данных из опросника выполняется следующий алгоритм:

### Шаг 1. Адаптация весов
1. Берем пользовательский ввод: объект `sliders = {К1: val, К2: val, ... К8: val}` (значения от 1 до 5).
2. Вычисляем промежуточные веса `w_tilde` для критериев группы **U**:
   `w_tilde[j] = w0[j] * k(sliders[j])`
3. Вычисляем коэффициент нормализации `gamma`:
   `gamma = 0.7609 / СУММА(w_tilde[j] для всех j из U)`
4. Формируем итоговый вектор весов `w_new` (длина 11):
   - Для `j` из **U**: `w_new[j] = w_tilde[j] * gamma`
   - Для `j` из **E**: `w_new[j] = w0[j]` (Скрытые переносятся без изменений).

### Шаг 2. Нормирование матрицы X (TOPSIS)
*Можно предвычислить один раз, так как от весов не зависит.*
Каждый элемент $x_{ij}$ делится на корень из суммы квадратов по столбцу:
$r_{ij} = x_{ij} / \sqrt{\sum_{i=1}^{4} x_{ij}^2}$

### Шаг 3. Взвешенная матрица V
Умножаем каждую ячейку нормированной матрицы на новые веса:
$v_{ij} = r_{ij} * w\_new[j]$

### Шаг 4. Определение Идеалов (A+ и A-)
Для каждого столбца `j` в матрице `V` находим максимум и минимум:
*   Если критерий **max** (К4, К5, К6, К8, К9, К10, К11): 
    *   $A^+_j = \max(v_{1j}, v_{2j}, v_{3j}, v_{4j})$
    *   $A^-_j = \min(v_{1j}, v_{2j}, v_{3j}, v_{4j})$
*   Если критерий **min** (К1, К2, К3, К7):
    *   $A^+_j = \min(v_{1j}, v_{2j}, v_{3j}, v_{4j})$  <-- *Обрати внимание, для min лучший идеал - это минимум!*
    *   $A^-_j = \max(v_{1j}, v_{2j}, v_{3j}, v_{4j})$

### Шаг 5. Расчет расстояний и коэффициента C
Для каждой альтернативы `i` (от 1 до 4) считаем евклидово расстояние до идеалов:
*   $S^+_i = \sqrt{\sum_{j=1}^{11} (v_{ij} - A^+_j)^2}$
*   $S^-_i = \sqrt{\sum_{j=1}^{11} (v_{ij} - A^-_j)^2}$

Итоговая оценка альтернативы `i`:
**$C_i = S^-_i / (S^+_i + S^-_i)$**

Альтернативы сортируются по убыванию $C_i$. Лучшая технология = max $C_i$.

## 5. Тексты для вывода результатов (Описания технологий)

Выводить описание для технологии, занявшей 1-е место:

*   **А1. Газобетон:** Сбалансированная технология без критических слабостей. Умеренная стоимость, отличная ремонтопригодность, достойный срок службы (80 лет) и высокая огнестойкость. Оптимальна для постоянного проживания, когда вы ищете золотую середину между ценой и качеством.
*   **А2. Деревянный каркас:** Конкурентоспособный вариант при акценте на экономию бюджета и экологичность. Низкая стоимость, короткие сроки возведения и хорошая ремонтопригодность. Однако требует пристального внимания к качеству монтажа и уступает конкурентам в огнестойкости.
*   **А3. Монолитный железобетон:** Абсолютный лидер по техническим показателям. Максимальный срок службы (120 лет), превосходная звукоизоляция, огнестойкость и климатостойкость. Оптимальный выбор для строительства капитального «родового гнезда» без жестких бюджетных ограничений.
*   **А4. СИП-панели:** Безоговорочный лидер по экономике. Минимальная стоимость строительства и самые сжатые сроки возведения. Идеальный вариант для инвестиционной недвижимости, баз отдыха или в случаях, когда заселиться нужно как можно быстрее при минимальном бюджете.
